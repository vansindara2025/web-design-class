Sector 1Fluid sizing

not yet

A size in pixels is fixed — it stays the same on a phone and on a cinema display. A size in percent is relative to the parent element, so it scales with the screen. Most fluid elements combine both: e.g. width: 60%; to scale, and max-width to stop it from growing forever on huge screens.

Make .s1-box take up 90% of its parent's width, but never exceed 800px. Center it horizontally.

Need a hint?

You'll need three declarations: width, max-width, and a margin trick for centering a block element — set the left and right margin to auto.

Sector 2Flexible rows

not yet

Flexbox turns on when you set display: flex; on a container. Once it's on, you control how children share the row with properties like justify-content (spacing along the row) and flex-wrap (whether children drop to a new line instead of squeezing forever).

Make .s2-row a flex container. Space its children apart with space-between, and let them wrap onto a new line when the row gets too narrow.

Need a hint?

Three declarations: display, justify-content, flex-wrap.

Sector 3A grid that adapts

not yet

CSS Grid divides a container into columns with grid-template-columns. Because it's just a normal CSS property, you can redeclare it inside a media query to change the column count once the screen crosses a certain width — that's the whole idea behind a responsive grid.

Set up .s3-grid as a grid with 1 column by default. Inside the two media queries already scaffolded below it, change it to 2 columns at 768px and 3 columns at 1024px.

Need a hint?

Use display: grid; then grid-template-columns: 1fr; for one column. For more columns, repeat 1fr that many times, e.g. 1fr 1fr for two.

Sector 4Show, hide, and restyle

not yet

A media query is a condition wrapped around normal CSS rules: @media (min-width: 600px) { ... } only applies the rules inside it once the screen is at least 600px wide. You can combine min-width and max-width in one query to target a range, like "only on tablets."

Two separate rules: hide .s4-extra completely below 768px. Turn .s4-panel's background orange only between 768px and 1023px.

Need a hint?

Hiding something uses display: none;. To target a range, combine min-width: 768px and max-width: 1023px in the same query with and.
